v0.1.0

Published 2026-08-22.

Changelog

  • 4e0c371 Bump all codeql-action refs to v4.37.7 together, not piecemeal
  • 5650c4e Fix CI: lower go.mod minimum from 1.27.0 to 1.25.0 (os.Root's floor)
  • 0a76680 Fix CI: pin setup-go to latest 1.25.x, not go.mod's literal 1.25.0
  • 61eec6e Fix audit findings: eviction races, DoS bailout, dead gauges, 413 test
  • d4c6770 Fix release CI: bump built-with Go from 1.25 to 1.27 (CVE-2026-46600)
  • 9339562 Fix release CI: cosign v3's sign-blob needs --bundle, not --output-*
  • 2622b9c Fix release CI: debug base was EOL Debian 12; VEX-suppress unfixable busybox CVE
  • c553dfc Release pipeline: ko + goreleaser, build->scan->sign->push, GOFIPS140 variant
  • dbed4ca Sprint 4: cache server core, Gradle/Maven-shared HTTP surface, CI baseline

Note on this release's evidence (added Sep 2026). v0.1.0 was built and published by the pre-remediation release pipeline: a snapshot build was scanned, and a separate build of the same commit was published, so these published images were not scanned before publication. They have been rescanned since at every severity with the published VEX applied — see the rescan runs for verdicts against the exact published digests. The signatures and provenance on this release are accurate about what they say — which CI run produced which digest — and say nothing about scanning. The next release is the first to carry the full evidence chain: one build, scanned and tested by digest, promoted without a rebuild.
